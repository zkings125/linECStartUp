# 研究问题、可识别性与输出目标

## 1. 代码最终要回答什么

对于装置参数向量

\[
\mathbf x=(R_0,a,B_T,B_V,L_{conn},p_0,f_{RF},P_{RF},
N_\parallel,\text{wall},\text{coil waveform}),
\]

建议把输出定义为四类，而不是只看最大 `I_p`：

1. **启动窗口**：`P(start | x)`、击穿延迟、失败原因和置信区间；
2. **机制分解**：`I_ohmic(t)`、`I_RF(t)`、`I_tail(t)`、`I_vertical_charge(t)`、体电子移交时间；
3. **拓扑事件**：CFS 候选/形成时间、闭合区面积、连接长度和 O/X 点；
4. **可迁移指标**：`Da_ion`、`E/N`、`n_e/n_critical`、`ω_c/ν`、`B_p/B_t`、`E/E_D`。

这样才能区分“某装置电流大”与“某装置更容易跨过击穿和拓扑门槛”。

## 2. 机制图谱

```text
EC 功率 ──┬─> 电子能量/电离 ──> n_e 增长 ──> 电导上升 ──> 环向电流
          ├─> 非 Maxwellian 热尾 ──> 开场线优先约束/轨道电流
          └─> k_parallel/共振 ──> 直接 RF 动量输入

垂直场/线圈 ──> 开场线连接长度与壁损失 ──┐
                                          ├─> B_p、ψ 拓扑 ──> CFS
气压/再循环 ──> 电离率与碰撞性 ───────────┘
```

同一条 `I_p(t)` 可能由不同支路组合产生，因此必须同时拟合 `n_e`、Hα/Dα、HXR、壁电流和磁拓扑，而不能只用 Rogowski 信号做机制判定。

## 3. 为什么低纵横比可能更有利，但不能先验定论

低纵横比通常同时改变多个量：`a/R0`、`B_p/B_t`、陷阱粒子比例、回旋共振位置、波可达性、垂直场需求和开场线几何。因此“ST 容易启动”可能是多个效应的联合结果：

- 较低环向场/较低频率组合可能提供更可行的 EC/EBW 共振和模式转换窗口；
- 相同 `I_p` 下极向场尺度 `B_p~μ₀I_p/(2πa)`、外部穿透场和 CFS 门槛的相对关系不同；
- 限制器、垂直场和短连接长度改变高能尾的壁损失与净环向电流；
- 低密度阶段的 `n_e/n_critical` 和密度演化可能让 RF 在不同时间窗内可达；
- CFS 形成前后的主导机制不同，ST 实验中常把预电离、轨道电流和 EBW 电流连续串联起来。

这些是待检验的因果假设，不是代码中的固定结论。`comparison.py` 和 `configs/device_matrix.json` 只负责在相同闭合下生成无量纲对照；真正的结论需要真实波传播、壁几何和实验数据。

## 4. 可识别性约束

| 只测什么 | 能识别什么 | 不能识别什么 |
|---|---|---|
| 仅 `I_p(t)` | 总电流增长 | RF 动量、轨道不对称、欧姆分量的相互替代 |
| `I_p+n_e+Hα` | 电离/电导时间尺度 | 高能尾方向性 |
| 再加 HXR/电子谱 | 热尾和 runaway 证据 | 空间拓扑细节 |
| 再加磁探针/场线重构 | CFS/LCFS 事件 | 微观碰撞截面误差 |
| 再加壁探针/壁电流 | 开场线损失与 EXL-50 所称 `j_TPC/j_VTF` 机制 | 波的局部 `k_parallel`，除非有传播诊断 |

因此实验计划和模型复杂度应同步升级；如果诊断不足，代码应输出“不可识别”而不是强行分配机制权重。注意 `j_TPC/j_VTF` 是论文中的局部/探针电流密度记号，不能仅凭代码的 `I_tpc_A`/`I_vtf_A` 别名宣称已经重现该诊断。
