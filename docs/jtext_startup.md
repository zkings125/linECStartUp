# J-TEXT 无感 EC 启动：代表性诊断与可检验解释

## 输入边界

`configs/jtext_ec_startup.ini` 不是某一炮的重建。它采用代表性装置参数
`R0=1.05 m`、`a=0.255 m`、`Bt=1.85 T`，以及 Xia *et al.* (2024,
DOI `10.1051/epjconf/202431302003`) 报告的 105 GHz / 500 kW 系统尺度。
用户实际启动炮的功率、偏振、发射角、气压、杂质、PF/CS 波形和壁状态尚未输入，
因此当前结果是机制筛选，不是对实验失败的拟合。

运行：

```powershell
python -m ecstartup analyze-startup-resonance configs/jtext_ec_startup.ini `
  --device J-TEXT --output runs/jtext_ec_startup/resonance_assessment.json
```

## 当前几何结论

真空环向场近似 `B(R)=B0 R0/R` 给出：

- 105 GHz 基频层 `B_res=3.751 T`，`R_res=0.518 m`，在代表性等离子体区间
  `R=0.795--1.305 m` 外；
- 105 GHz 二次谐波层 `B_res=1.876 T`，`R_res=1.036 m`，在区间内。

所以，若用户当时使用的是 105 GHz X2 系统，则“缺少二次共振层”与这个简单几何
计算不符，不能作为单一解释。若实际频率不是 105 GHz，应修改配置后重新判断；
代码不会把 EXL-50U 的 28/50 GHz 自动移植到 J-TEXT。

## 更合理的失败链条

1. **有共振层不等于有冷启动吸收。** X2 对极冷、低密度初始电子的单程吸收可很弱，
   需要有限垂直动量/温度或已有高能尾；这可能形成“先要尾电子才能有效造尾电子”的门槛。
2. **加热不等于净电流。** 近垂直 X2 首先增加 `p_perp`。无显著 `k_parallel`、
   速度空间不对称损失、垂直电荷分离或轨道选择时，正负 `p_parallel` 贡献大致抵消。
3. **常规纵横比的开场线约束较弱。** 当前代表性 `A=R0/a≈4.12` 且没有 TPC
   镜像线圈输入，几何捕获代理接近零。与 ST 相比，高能电子更难在 CFS 前积累到足以
   产生自场和闭合面的水平。
4. **气压存在双重作用。** 增压可加速电离，却同时提高电子-中性碰撞、俯仰散射和
   高能尾热化/损失。因此完全可能出现 H-alpha/密度上升但净电流仍未建立；这与
   “能击穿”和“能形成持续 Ip”是两个阈值相符。
5. **CFS 前不能用 EFIT 补答案。** 上述判断应由真实 PF/TF/CS 波形、场线到壁长度、
   逐时刻偏振/光路、气压和杂质输入检验，不能借用平顶期 GS 平衡。

## 下一轮需要的实验输入

优先级依次为：实际 EC 频率/模式/功率波形和镜面角度；PF/TF/CS 电流波形；
压强与注气时序；H-alpha、硬 X 射线/ECE 和 Ip 原始时序；壁/限制器几何。
这些数据可以分别约束吸收、快电子形成、开场线损失和电流不对称，避免仅凭最终
“启动成功/失败”反推多个不可辨识参数。
