# GitHub发布前检查清单

本文区分“代码可以公开复现”与“模型可以定量预测装置启动”。前者是首个GitHub版本的
最低要求；后者需要持续的物理实现和实验验证，不能通过README措辞替代。

## 首次公开前必须完成

- 已采用远端仓库中维护者选择的 BSD-3-Clause `LICENSE`；发布时检查源码包确实包含它。
- 确认 `exl50u_startUpShots/`、`runs/`、`output/`、视频、临时PDF和可能受限的诊断数据
  不进入普通Git历史；需要公开的数据应单独给出许可、校验和、来源和下载说明。
- 在全新虚拟环境执行 `pip install -e '.[dev]'`、README最小案例、完整测试和包构建。
- 让GitHub Actions在支持的最低/最高Python版本通过；失败时不得创建稳定版标签。
- 冻结首个公开schema版本，说明后续输入/输出兼容政策。
- 检查所有外部数据、论文图、PPT截图、字体和第三方代码的再发布权利。
- GENRAY回归fixture默认仅本地保存并从Git/sdist排除；只有获得明确再分发授权后才能加入发行包。
- OpenADAS manifest已经记录URL和SHA-256，但仍须核对发布时适用的OpenADAS再分发条款。
- 仓库URL和GitHub Issues已补充；正式稳定版前仍需补充维护者/机构和安全或数据泄露联系方式。
- 创建 `CITATION.cff`；有正式发布时归档到Zenodo或同类服务并记录DOI。

仓库已经提供 `.gitignore`、BSD-3-Clause许可证、CI、包构建配置、快速README、配置索引、
仓库URL和贡献说明；维护者/机构身份、CITATION与DOI仍需由维护者决定。

## 首个alpha版本必须稳定的代码接口

1. `python -m ecstartup validate/run/postprocess` 和 `ecstartup`控制台入口。
2. `SimulationConfig`严格校验、未知字段拒绝、SI单位后缀和resolved config归档。
3. `summary.json`、`events.json`、`diagnostics.csv`、`state.nc`的schema和单位元数据。
4. 最小案例、EXL主模板、至少一个磁场案例、F-P案例和阈值扫描的回归测试。
5. 所有可选后端缺依赖或缺输入时给出明确错误，不允许静默退回代理模型。
6. 每项装置结论携带证据等级、输入来源、数值收敛和设备质量门结果。

## 现阶段必须继续实现或完善的物理模块

这些项目不会阻止发布“alpha机制研究代码”，但会阻止宣称能够准确预测任意托卡马克
是否启动及启动电流。

### P0：决定启动与电流的核心闭合

- 用炮级PF/TF/CS/TPC/VFC波形和真实第一壁替代解析磁场/矩形壁，逐时刻计算场线命中、
  连接长度、镜像捕获和轨道损失；加入线圈-等离子体互感和涡流结构。
- 建立EXL-50U成功/失败炮验证集，统一 `Ip、ne、H-alpha/D-alpha、HXR/ECE、loop voltage`
  时间基准，冻结拟合集并保留独立验证集。
- 把H2/D2振转激发、解离、分子离子和材料相关壁反应接入版本化数据库；当前H原子ADF11
  快照不足以覆盖启动化学。
- 对1D-2V空间输运、电离、壁损失、双极电势/鞘层和F-P电流反馈做粒子、能量、动量和
  电荷守恒的联合时间步/网格收敛。

### P0：EC、X-B、O-X-B与Dql证据链

- 按时间输入 `ne(R,Z,t)`、`Te(R,Z,t)`、真空线圈场和端口波束；无空间密度时不得判断
  O截止、UHR或模式转换。
- 直接X-B已加入R/L截止、UHR、采样倏逝层宽度和入射快/慢X支诊断；下一步仍需
  由热全波解给出倏逝层光学厚度、转换效率和本征模身份。
- 用非局域热介电张量和经过网格/PML收敛的全波解分离O、X和EBW本征模；当前局部
  Nedelec/FLR后端不能单独证明产生了真实EBW。
- 从全波有符号 `k_parallel/k_perp` 波谱生成空间及速度空间归一化 `D_ql`，严格闭合
  注入、反射、透射、PML、EBW输出、吸收功率和波粒平行动量。
- 用相同初态分别运行直接电磁EC、EBW和混合 `D_ql` 消融，只有F-P电流矩与波动量闭合
  后才报告ECCD/EBWCD大小。

### P1：跨装置可迁移性

- 每台装置使用独立输入来源和验证集，不共享为某一文献锚点反演的A/W效率。
- 把环径比扫描与真实线圈空间、端口可达性、高比压和多共振层分开，避免把相关性写成因果。
- 对常规托卡马克失败案例同时检查二次谐波可达性、波束/偏振、开场线损失、气压窗口和
  捕获不对称，不能只选择一种事后解释。

## 软件质量仍需加强

- 为命令行和JSON/NPZ/NetCDF schema增加版本兼容测试及迁移说明。
- 为大网格Braams--Karney、1D-2V和全波模块建立性能基准、内存上限和可中断检查点。
- 增加属性测试或随机守恒测试，覆盖极低密度、零场、截止/共振奇点和输入越界。
- 在可公开的小型数据上建立端到端回归，避免CI依赖300 MB本地炮数据。
- 逐步启用ruff和mypy质量门；首次启用前先清理现有告警，避免CI长期处于红色。

## 发布等级建议

- `v0.1.x-alpha`：公开接口、机制分析、示例和质量门；明确禁止设备级准确性声明。
- `v0.2.x-beta`：真实EXL输入管线、守恒/收敛测试和冻结的成功/失败验证集通过。
- `v1.0.0`：输入输出schema稳定，多装置独立验证通过，论文和代码版本可一一复现。
