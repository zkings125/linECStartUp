# 验证、校核和实验对照

## 单元与解析基准

1. **单位/配置**：负压强、反向边界、未知字段必须拒绝；几何体积与解析圆环一致。
2. **反应率**：在选定 `E/N,T_e` 点与 LXCat/BOLSIG+/LoKI-B 表格对照，并记录相对误差和数据库版本。
3. **Townsend**：固定 `K_ion`、`K_att` 和损失时间时，数值 `n_e(t)` 与指数增长/衰减解析解一致。
4. **电路**：固定电导时与 `L dI/dt+R I=V` 的解析阶跃解一致。
5. **磁场**：等效环流场的方向、`B_p∝I_p` 和零电流极限通过测试。
6. **拓扑**：穿透场大于极向场时无闭合候选，反之 `closed_fraction` 单调增加。

## 1D/2V 升级后的基准

- 单场线漂移-扩散与 Bohm 鞘层；
- Poisson 与准中性极限的交叉验证；
- 电子 Boltzmann 方程的 swarm 迁移率、扩散系数和 Townsend 系数；
- Fokker–Planck 碰撞算子的粒子/能量守恒和 Maxwellian 平衡；
- 射线追踪在均匀磁场回旋共振位置的解析验证；
- Grad–Shafranov 在 Solov'ev/圆柱解析解上的残差和网格收敛。

## 实验数据接口

建议按同一时间基准导入：

| 诊断 | 约束 |
|---|---|
| 回路电压/线圈电流 | `E_loop`、外部磁场和电路方程 |
| Rogowski | `Ip(t)` 与三项电流分解 |
| 干涉仪/微波反射 | `n_e(t)`、击穿和预电离时刻 |
| Hα/Dα、可见光、软 X | 电离/激发/杂质辐射时序 |
| 电子谱温度/硬 X | 非 Maxwellian 热尾和 `Dreicer_ratio` |
| 磁探针/EFIT 重构 | `ψ`、O/X 点、LCFS/CFS 时刻 |
| 壁电流/限制器探针 | 开场线损失、再循环和轨道不对称 |

模型比较应给出误差条和参数不确定度，不只报告一个最佳拟合曲线。推荐留一装置交叉验证，避免把某一装置的 `A/W` 当成普适标度律。
