# 数值方法与稳定性

## 刚性来源

电子沿线损失、电子-中性碰撞、分子反应、能量弛豫和电流磁扩散跨越 ns–ms 多个时间尺度。因此默认使用 `scipy.integrate.solve_ivp(method="BDF")`，并限制 `max_step_s`。`RK45` 只适合无强刚性的教学测试。

## 正性与尺度

状态量跨越十多个数量级。求解器使用分量绝对容差；每个输出状态再投影到 `n_e,n_i,n_n,U_e,n_hot,U_h≥0`。这只是 MVP 的安全网，不是守恒的正性有限体积格式。升级到 1D 后应改用守恒有限体积、隐式反应步和正性限制器，最好对密度/能量使用对数变量。

## 收敛检查

至少运行三组：`dt`、`dt/2`、`dt/4`，比较击穿时刻、CFS 候选时刻、峰值 `Ip` 和总能量残差。空间模型还要做网格和速度网格收敛。任何事件若随步长改变超过实验时间分辨率，应标记为未收敛。

## 守恒审计

生产版每一步应输出：

```text
粒子残差 = d(N_e+N_i+N_n)/dt - 外部馈气/泵浦/壁再循环净项
能量残差 = P_in - P_out - d(U_e+U_h+U_i)/dt
电路残差 = V_loop - L*dIp/dt - R*Ip - V_drive
divB 残差 = ||∇·B|| / ||B||
```

残差应和配置容差一起写入 `state.nc`，不能只在日志里打印“收敛”。
