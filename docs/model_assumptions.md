# 模型假设、适用范围与失效条件

## v0.1 实际实现

| 组件 | 当前闭合 | 适用范围 | 失效信号 |
|---|---|---|---|
| 几何 | 圆截面、体平均 | 软件联调、参数敏感性 | 强非圆性、3D 误差场、复杂限制器 |
| 反应率 | 平滑等效 `K(E/N,T_e)` | 量级测试 | 需要绝对击穿阈值、分子通道显著 |
| 电子分布 | `T_e` + 热尾两个矩 | EEDF 接近单峰、只看趋势 | 多峰/强 runaway/强各向异性 |
| 壁损失 | `L_conn/v_th`、Bohm 量级 | 开场线初筛 | 鞘层、漂移、再循环决定结果 |
| 电荷闭合（可选） | 总正电荷连续性 + 玻尔兹曼抑制反求双极势 | 避免 0D 电子/离子独立损失造成宏观非中性 | 势垒限幅、负目标通量、空间鞘层或二次电子能谱关键 |
| 磁场线圈 | `circular/TPC/VFC` 基础 provider，局部 `CompositeMagneticField`，或圆环 `BiotSavartMagneticField` | 接口联调、波形敏感性、轴对称线圈场验证 | 非圆形/有限截面线圈、场线壁命中、3D 误差场和 GS 平衡 |
| ECRH | 0D 中仍为处方吸收功率；另有冷 Stix Hamiltonian 射线和 O cutoff/UHR/EBW 几何候选诊断 | 低密度功率扫描、O/X 可传播性、O-X 角度窗口初筛 | X-B 效率、热 EBW 色散/吸收、准线性 EBWCD、焦散或全波干涉关键 |
| 电流 | 降阶 L-R + 三项分解 | 机制消融 | 需要真实电流剖面/自洽平衡 |
| CFS | 默认 `circular_surrogate`；可另行使用 `FieldLineTopologyDetector` 扫描 | 事件管线和场线接口测试 | 未经 GS/壁网格收敛的任何装置级 CFS 时刻结论 |
| 多物种/壁（可选） | 相邻电荷态 + 0D 壁库存 + 阈值溅射 | 守恒联调、杂质敏感性和后端接口测试 | 绝对辐射、材料空间分布、分子燃料化学或电荷态依赖输运关键 |

`closed_confinement_gain` 默认是 0，表示 CFS 诊断不反过来改变动力学；只有在专门的敏感性/教学案例中才打开这个阶段反馈。打开后仍不能替代真实的开闭场线输运切换。

`species_wall` 默认关闭。启用时内置 `AnalyticAtomicRateProvider` 仍是 surrogate，不得标记为 ADAS；装置预测前必须以版本化 ADF11 数据替换，并验证温度/密度插值范围。当前壁库存只记录等离子体沉积/滞留粒子，不代表有限厚度壁材料库存。

`charge_closure` 默认使用 `legacy` 以保证旧案例可复现；新的 DYON-like 示例使用 `ambipolar`。双极势是体平均等效量，不是局域鞘电势。势垒触及上下限时必须检查 `ambipolar_flux_limited` 和 `charge_continuity_relative`，不能继续把结果称为准中性解。

TPC 的 `tpc_mirror_ratio`/`tpc_trapped_fraction` 是显式的降阶闭合；当前解析
provider 只在横截面上修正 `B_phi`，并不沿真实场线求解 `B(s)`、损失锥或漂移。
因此 `FieldLineTracer` 输出的数值 `mirror_ratio` 不能直接当作输入镜像比，
装置级结论必须用实际线圈/GS 场线和动理学损失模型重新标定。

## 不能从 v0.1 直接得出的结论

- 不得把 `current_drive_A_per_W` 当作跨装置 ECCD 效率；
- 不得把 `closed_fraction>0` 当作真实 LCFS 已形成；
- 不得用单一 `I_p` 阈值外推不同线圈、误差场或壁结构；
- 不得在高碰撞分子等离子体中省略解离、振转激发和多价离子；
- 不得在 `E/E_D ≳ 1` 或强非 Maxwellian 时只用 Spitzer 电阻率；
- 不得把仿真中的 `Te` 当作诊断测得的谱温度，除非建立诊断前向模型。

## 升级前的质量门

每次替换一个闭合模块，都应同时满足：

1. 单位和参数 schema 不变；
2. 总粒子数、电子能量和电路功率残差有明确容差；
3. 时间步、网格和速度网格收敛；
4. 与一个解析基准和至少一个实验诊断时序对照；
5. 记录数据源版本、拟合区间和不确定度；
6. 做机制消融（仅环向场、仅 RF、仅轨道不对称、联合）。
